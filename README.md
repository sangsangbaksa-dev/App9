# 구독 갱신 장부

정기 구독의 갱신일과 월/연 지출을 관리하는 정적 웹앱 (빌드 단계 없음, 외부 스크립트 없음).

## 기능
- 구독 추가/수정/삭제 (서비스명, 카테고리, 금액, KRW/USD 통화, 환율, 매월/분기/매년 주기, 다음 갱신일, 사용 중/해지 예정)
- USD는 입력한 환율(기본 1350원)로 원화 환산
- 지난 갱신일은 주기만큼 자동으로 다음 미래 날짜로 넘김
- 월/연 합계, 카테고리별 도넛 차트, 사용 중 개수
- 7일/30일 내 갱신 목록 (D-n 배지, 긴급도 색상)
- 해지 예정 항목을 모두 해지했을 때의 절약액
- 갱신 목록을 .ics 캘린더 파일로 내보내기 (종일 일정, 하루 전 알림)
- 예시 데이터(예시 데이터 표시), 전체 삭제(확인 대화상자), 라이트/다크 테마

## 구조
- `logic.js`: DOM 접근 없는 순수 함수 (날짜 계산, 비용 환산, 검증, ICS 생성)
- `app.js`: DOM 렌더링과 이벤트 처리만 담당
- `tests/logic.test.js`: logic.js 단위 테스트

## 실행
- 서버: `python3 -m http.server 8000` 후 http://localhost:8000 접속
- 테스트: `node --test` (Node 22에서는 디렉터리 인자 `tests/`가 거부되므로 인자 없이 실행하면 tests/를 자동 탐색)
