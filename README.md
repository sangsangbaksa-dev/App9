# 구독 갱신 장부

정기 구독의 갱신일과 월/연 지출을 관리하는 정적 웹앱 (빌드 단계 없음, 외부 스크립트 없음).

## 기능
- **구독 관리**: 추가/수정/삭제 (서비스명, 카테고리, 금액, KRW/USD 통화, 환율, 매월/분기/매년 주기, 다음 갱신일, 사용 중/해지 예정)
- **메모와 체험 종료일**: 구독마다 메모(200자 이내)를 적고, 무료 체험 종료일을 넣을 수 있음
- **체험 알림**: 체험이 7일 안에 끝나거나 막 끝난 구독을 상단에 표시. “알림 끄기”로 숨길 수 있고, 종료일을 바꾸면 다시 나타남
- **키보드**: `/` 키로 검색창에 포커스
- **공유 요금 나누기**: 함께 쓰는 인원을 입력하면 카드와 입력 화면에 내 부담 금액(월)을 표시
- **환산**: USD는 입력한 환율(기본 1350원)로 원화 환산
- **자동 갱신일**: 지난 갱신일은 주기만큼 자동으로 다음 미래 날짜로 넘김 (월말 날짜는 말일로 보정)
- **상단 고정 바**: 스크롤해도 이번 달 월 지출 합계가 보임
- **요약**: 월/연 합계, 사용 중 개수, 카테고리별 도넛 차트
- **곧 갱신**: 7일/30일 내 갱신 목록 (D-n 배지, 긴급도 색상)
- **12개월 지출 예측 (추정)**: 구독별, 월별 예상 결제액을 표로 보여 줌. 가격 인상, 해지, 환율 변동은 반영하지 않음
- **갱신 달력 (추정)**: 이번 달 달력에 결제 예정일을 점으로 표시하고, 아래에 목록을 함께 보여 줌
- **월 지출 추이 (추정)**: 최근 12개월 막대 차트. 현재 구독을 기준으로 역산한 값이며 실제 결제 내역이 아님
- **월 예산**: 월 목표 지출을 설정하면 사용률 진행 바와 초과 경고 표시 (추이 차트에 예산선 표시)
- **해지 예정 절약액**: 해지 예정 항목을 모두 해지했을 때의 월/연 절약액
- **해지 시뮬레이터**: 구독을 체크해 해지했을 때의 절약액과 남는 월 지출을 미리 계산 (저장되지 않음)
- **검색/필터/정렬**: 서비스명 검색, 카테고리·상태·통화 필터, 다음 갱신일/월 비용/이름 순 정렬
- **중복 경고**: 이름이 같은 구독이 여러 개면 상단 안내와 카드 배지 표시
- **가격 변경 기록**: 금액이나 통화를 수정하면 날짜와 이전/이후 가격을 기록하고 카드에서 펼쳐 볼 수 있음
- **내보내기**: 갱신 목록을 .ics 캘린더 파일로 (종일 일정, 하루 전 알림), 전체 구독을 CSV 파일로 (엑셀에서 한글 깨짐 없음)
- **JSON 백업과 복원**: 구독 목록과 예산을 JSON 파일로 저장하고 다시 가져옴. 같은 ID는 파일 내용으로 바뀌고 나머지는 추가됨
- **빈 상태 안내**: 구독이 없으면 그림과 함께 추가/예시 데이터 버튼을 보여 줌
- **예시 데이터**: 예시 데이터 표시, 전체 삭제(확인 대화상자)
- **테마**: 라이트/다크 전환 (기본값은 시스템 설정 따름)
- **저장**: 모든 데이터는 이 브라우저의 localStorage에만 저장

## 구조
- `logic.js`: DOM 접근 없는 순수 함수 (날짜 계산, 비용 환산, 검증, 추이/예측/달력/체험 계산, 필터·정렬, 중복 탐지, ICS/CSV/JSON 생성·파싱)
- `app.js`: DOM 렌더링과 이벤트 처리만 담당
- `styles.css`: 색상과 간격 토큰(`:root`), 라이트/다크 변형, 컴포넌트 스타일
- `index.html`: 마크업
- `tests/logic.test.js`: logic.js 단위 테스트

### 저장 형식
- 구독 목록: localStorage `renewal-ledger:v1` (배열). 아래 선택 필드는 없으면 기본값으로 읽음
  - `history`: 가격 변경 기록 (기본 빈 배열)
  - `trialEnds`: 체험 종료일 `YYYY-MM-DD` (기본 빈 문자열)
  - `sharers`: 함께 쓰는 인원, 1~20 (기본 1)
  - `notes`: 메모 (기본 빈 문자열)
- 예산: localStorage `renewal-ledger:budget` (원 단위 정수, 0이면 예산 없음)
- 테마: localStorage `renewal-ledger:theme`
- JSON 백업: `{ app: "renewal-ledger", version: 2, exportedAt, budget, subscriptions: [...] }`

## 실행
- 서버: `python3 -m http.server 8000` 후 http://localhost:8000 접속
- 테스트: `node --test` (Node 22에서는 디렉터리 인자 `tests/`가 거부되므로 인자 없이 실행하면 tests/를 자동 탐색)

갱신일은 `renewalAnchor`에 원래 결제일을 함께 보관합니다. 월말을 지난 뒤 다시 열어도 1월 31일 → 2월 28일 → 3월 31일로 유지되며, 결제일이나 주기를 직접 바꾸면 기준일도 바뀝니다. 기존 기록은 현재 저장된 갱신일을 기준으로 시작합니다.
